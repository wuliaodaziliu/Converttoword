# PDF转Word工具 - Windows 打包方案

## 概述

由于开发环境为 macOS，无法在本地交叉打包 Windows exe。采用 **GitHub Actions CI** 在 Windows Runner 上自动构建并发布。

---

## 打包架构

```
macOS 开发 → GitHub 推送 → Windows Runner (pyinstaller) → Artifact 下载
```

---

## 文件结构

```
.github/
└── workflows/
    └── build.yml       # CI 构建配置
spec/
└── 打包方案.md         # 本文档
poppler/                # Poppler 二进制（需手动下载）
src/
├── converter.py
├── gui.py
└── logger.py
build_spec.py
requirements.txt
```

## 构建流程

### 1. 下载 Poppler

从 [poppler-windows releases](https://github.com/oschwartz10612/poppler-windows/releases) 下载预编译版（如 `poppler-24.08.0-0.zip`），解压到项目根目录 `poppler/`。

目录结构：
```
poppler/
├── Library/
│   ├── bin/        # poppler.dll 等
│   └── lib/        # 依赖库
```

### 2. 修改 converter.py

在 `convert` 方法开头加入 Poppler 路径设置：

```python
import os
_base = os.path.dirname(os.path.abspath(__file__))
os.environ["POPPLER_PATH"] = os.path.join(_base, "poppler", "Library")
```

### 3. 修改 build_spec.py

将 Poppler 打包进 exe：

```python
a = Analysis(
    ['src/gui.py'],
    ...
    datas=[
        (os.path.join(os.path.dirname(__file__), "poppler", "Library"), "poppler/Library"),
        ('src', 'src'),
    ],
    hiddenimports=['pdf2image', 'PIL', 'Pillow', 'docx'],
    ...
)
```

### 4. 创建 GitHub Actions 配置

`.github/workflows/build.yml`：
- 触发：push tag 或手动 dispatch
- 环境：Windows latest
- 步骤：
  1. checkout
  2. 安装 Python 3.11
  3. 安装 poppler（下载或从缓存）
  4. `pip install -r requirements.txt`
  5. `pyinstaller build_spec.py`
  6. 上传 Artifact（保留 30 天）

### 5. 构建产物

生成的 exe 在 `dist/PDFToWordConverter.exe`，大小约 200-400MB。

## 触发构建方式

- **方式 A**：推送 tag
  ```bash
  git tag v1.0.0
  git push origin v1.0.0
  ```
- **方式 B**：GitHub 网页手动 trigger workflow

---

## 注意事项

- Poppler 大小约 20MB，artifact 总计约 300MB
- 构建时间约 5-10 分钟
- 不需要上传到 PyPI 或 GitHub Release，仅通过 Artifact 下载即可
