# PDF转Word工具 - 需求文档

## 1. 项目概述

- **项目名称**: PDF转Word工具
- **核心功能**: 将 PDF 文件的每一页截图，插入 Word 文档，保留原始排版
- **目标用户**: Windows 业务人员
- **开发者**: 昏昏的小猪仔（macOS 开发）
- **输出形式**: Windows 可执行 exe

---

## 2. 功能需求

### 2.1 核心功能

| 功能 | 描述 |
|------|------|
| PDF 多文件转换 | 支持同时选择多个 PDF 文件并行转换 |
| 截图嵌入 Word | 每页渲染为图片，插入 Word |
| 可配置 DPI | 默认 96，高清 150，用户可配置 |
| 可配置图像格式 | 默认 JPG，可配置 PNG |
| 图像质量不变 | 图片体积小但清晰度不降 |
| 自选输出目录 | 用户指定输出位置 |
| 输出文件名 | 与原始 PDF 同名，冲突自动重命名 |

### 2.2 用户界面

- **框架**: Tkinter（Python 标准库）
- **尺寸**: 固定 666px × 666px，禁止拉伸
- **元素**:
  - PDF 文件列表（支持多选）
  - 输出目录选择
  - DPI 配置（下拉或输入）
  - 图像格式配置（JPG/PNG）
  - 开始转换按钮
  - 进度条（实时显示转换进度）
  - 状态/日志显示区

- **布局（草图）**:
```
┌─────────────────────────┐
│    PDF 转 Word 工具     │
├─────────────────────────┤
│ PDF文件: [列表/选择按钮] │
│ 输出目录: [浏览按钮]     │
│ DPI: [96] 格式: [JPG]   │
│                         │
│     [开始转换]          │
│ ████████░░░░  67%       │
│ 状态: 正在转换第3页...   │
└─────────────────────────┘
```

### 2.3 输入输出

- **输入**: 单个或多个 PDF 文件（通过文件选择对话框）
- **输出**: Word 文档（.docx 格式）
- **输出路径**: 用户指定目录
- **命名规则**: `{原PDF文件名}.docx`，冲突时自动重命名（如 `报告_1.docx`）

## 4. 转换流程

```
用户选择多个PDF → 解析PDF页数 → 并行转换（每文件独立） → 每页截图 → 插入Word → 保存 → 进度更新
```

1. 用户选择多个 PDF 文件
2. 解析每个 PDF 的页数
3. 并行处理每个 PDF（多线程）
4. 每页使用 pdf2image 渲染为图片
5. 图片压缩后插入 Word 文档
6. 保存至用户指定目录，文件名冲突则重命名
7. 实时更新进度条和状态日志

---

## 5. 错误处理与日志

### 5.1 错误处理

- 所有异常捕获，显示友好提示
- 原始报错信息保留在日志文件中
- 不因单个文件失败中断整个任务（批量继续）

### 5.2 日志

- 日志文件默认输出到用户桌面
- 日志文件名: `PDF转Word工具_YYYYMMDD.log`
- 日志级别: INFO / WARNING / ERROR
- 日志内容含时间戳、来源、详情
