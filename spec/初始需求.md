# PDF转Word工具 - 初始需求文档

## 1. 项目概述

- **项目名称**: 文件转Word工具 (FileToWordConverter)
- **核心功能**: 将 PDF、PPT 文件的每一页以截图方式原样嵌入到 Word 文档中，保留原始排版
- **目标用户**: 业务人员（使用 Windows 系统）
- **开发者**: 昏昏的小猪仔（使用 macOS 开发）

---

## 2. 功能需求

### 2.1 核心功能

| 功能 | 描述 |
|------|------|
| PDF 转 Word | 将 PDF 文件每一页渲染为图片，插入 Word 文档 |
| PPT 转 Word | 将 PPT 文件每一页渲染为图片，插入 Word 文档 |
| 保持排版 | 截图方式确保原始布局完全一致 |
| 文件命名 | 输出文件 = 原文件名 + "转换" |

### 2.2 输入输出

- **输入**: 单个 PDF 或 PPT 文件（通过文件选择对话框选择）
- **输出**: Word 文档（.docx 格式）
- **输出路径**: 与输入文件相同目录

### 2.3 用户界面

- **UI 框架**: Tkinter（Python 内置，跨平台）
- **界面元素**:
  1. 输入文件路径输入框 + 浏览按钮
  2. 输出路径（自动生成，仅显示）
  3. 转换按钮
  4. 状态/日志显示区域

- **界面布局**（草图）:

```

│       PDF/PPT 转 Word 工具          │
├─────────────────────────────────────┤
│ 输入文件: [_______________] [浏览]   │
│ 输出文件: [_______自动生成_______]   │
│                                     │
│         [开始转换]                  │
│                                     │

└─────────────────────────────────────┘
```

## 3. 技术方案

### 3.1 技术选型

| 组件 | 技术方案 | 原因 |
|------|----------|------|
| 开发语言 | Python 3.9+ | 跨平台，库丰富 |

## 4. 跨平台构建说明（重要）

### 4.1 构建环境要求

由于开发者在 **macOS** 编写代码，业务人员在 **Windows** 使用：

1. **方案 A（推荐）**: 在 Windows 虚拟机/主机上执行最终打包
   - 在 Windows 上安装 Python + 所有依赖
   - 运行 PyInstaller 生成 exe
   - 分发 exe 给业务方

2. **方案 B**: 使用 GitHub Actions CI 在 Windows 环境打包
   - 代码提交后自动在 Windows runner 构建 exe
   - 自动生成 Release 供下载

### 4.2 注意事项

- PyInstaller 只能在目标操作系统上构建对应格式的 exe
- macOS 上无法直接构建 Windows exe（需要交叉编译或虚拟机）
- 建议使用方案 A 或方案 B

## 5. 详细功能流程

### 5.1 转换流程

```
用户选择文件 → 识别类型(PDF/PPT) → 逐页渲染为图片 → 写入Word文档 → 保存
```

### 5.2 PDF 转换流程

1. 读取 PDF 文件
2. 使用 pdf2image 将每页转为 PIL Image
3. 临时保存图片（或内存中处理）
4. 使用 python-docx 创建 Word 文档
5. 每页图片作为一个段落/图片插入 Word
6. 保存为 `{原文件名}转换.docx`

### 5.3 PPT 转换流程

1. 读取 PPT 文件
2. 使用 python-pptx 遍历每张幻灯片
3. 将幻灯片渲染为图片（使用 pptx 的 shapes 或额外库）
4. 使用 python-docx 创建 Word 文档
5. 每页图片插入 Word
6. 保存为 `{原文件名}转换.docx`

### 5.4 PPT 渲染特殊说明

python-pptx 无法直接渲染幻灯片为图片，需要：
- 使用 `python-pptx` 读取幻灯片内容
- 结合 `Pillow` 或其他方式渲染
- **备选方案**: 使用 LibreOffice 命令行进行转换，或使用 `Aspose.Slides`（商业）

## 6. 非功能需求

### 6.1 性能要求

- 单次转换文件大小限制: 100MB 以内
- 转换时间参考: 每页约 1-3 秒

### 6.2 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 文件格式不支持 | 弹出提示"仅支持 PDF 和 PPT 文件" |
| 文件读取失败 | 显示具体错误信息 |
| 转换中途失败 | 保留已生成的部分，提示用户 |

### 6.3 界面要求

- 窗口固定大小，禁止拉伸
- 编码统一使用 UTF-8
- 支持中文文件名和路径
